Credential process · Ceph RGW

Google identity in. AWS credentials out.

Exchange Google OIDC tokens for short-lived AWS-compatible credentials—without storing a long-lived access key.

Linux x86_64 · static Linux aarch64 · static macOS Apple Silicon
01

Ask Google

Uses your existing gcloud session and service-account impersonation to mint an identity token.

02

Exchange with STS

Calls AssumeRoleWithWebIdentity at your AWS-compatible or Ceph RGW endpoint.

03

Use AWS tools

Returns standard credential_process JSON while the identity token stays in your system keyring.
