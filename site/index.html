aws-google-oidc GitHub ↗

Open source · credential process

Google identity in. AWS credentials out.

Exchange a Google identity token for short-lived AWS-compatible credentials. Built for S3-compatible services backed by Ceph RGW. 

curl --proto '=https' --tlsv1.2 -LsSf \
  https://dialohq.github.io/aws-google-oidc/install.sh | sh

Static Linux binaries for x86_64 and aarch64. Apple Silicon macOS.

Nix

Run from the flake.

nix run nixpkgs#cachix -- use aws-google-oidc
nix run github:dialohq/aws-google-oidc -- --profile ceph

Configuration

Use it as an AWS credential process.
